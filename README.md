# Qt Bridges

> Copyright (C) 2025 The Qt Company Ltd.
> SPDX-License-Identifier: LicenseRef-Qt-Commercial OR LGPL-3.0-only

Qt Bridges is a technology that enables developers to provide application logic to Qt Quick
application, by offering a new and simple API, that aim to stay as closer as possible to the host
language style and principles.

In this meta-repository you will find a reference to the current bridges in development:
* [Java/Kotlin](https://code.qt.io/cgit/qt/qtbridge-java.git/)
* [C#](https://code.qt.io/cgit/qt/qtbridge-csharp.git/)
* [Swift](https://code.qt.io/cgit/qt/qtbridge-swift.git/)
* [Rust](https://code.qt.io/cgit/qt/qtbridge-rust.git/)
* [Python](https://code.qt.io/cgit/qt/qtbridge-python.git/)

## Documentation

The snapshots of the project documentation can be found [online in the Qt documentation
page](https://doc-snapshots.qt.io/qtbridges-dev/index.html).

The instructions to build the documentation can be found in the [doc/ directory](doc).
